
# FinSight AI

## A Personal Finance Intelligence Platform

FinSight AI is a final-year project designed to help users understand transaction history, analyze spending patterns, and explore data-driven financial insights.

## Planned Features

- Authentication and user-specific data
- CSV transaction import and validation
- Financial analytics and explainable health indicators
- Spending segmentation and anomaly detection
- Expense forecasting
- Interactive dashboard
- Data-grounded AI Copilot
- What-if financial simulation

## Technology Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express
- Database: MongoDB Atlas, Mongoose
- ML Service: Python, FastAPI, scikit-learn

## Project Structure

- `frontend/` — User interface
- `backend/` — REST API and business logic
- `ml-service/` — Machine-learning service
- `docs/` — Requirements and diagrams
- `sample-data/` — Synthetic development data

## Development Status

Week 1: Requirements and project setup.

## Privacy and Limitations

Use synthetic or anonymized financial data during development.
Predictions and AI explanations are estimates, not guaranteed outcomes or professional financial advice.
